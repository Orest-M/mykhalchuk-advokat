## 0.1 Правила для исполнителя любой задачи

1. Прочитать `TASKS.md` и `CLAUDE.md`. Не выходить за рамки своей задачи, не «улучшать» соседние секции.
2. Никаких новых зависимостей сверх перечисленных в задаче без обоснования в отчёте.
3. Все строки интерфейса — через словарь i18n (`src/i18n/`), в компонентах хардкода украинского текста нет.
4. Все данные, которые заказчик заменит позже (телефон, email, график, ссылки на мессенджеры, ID аналитики), лежат в `src/config/site.ts` и `.env`, помечены `// TODO(client)`.
5. Перед сдачей: `npm run check` и `npm run build` проходят без ошибок; страница проверена в браузере на 375 px и 1440 px; отчёт в чате — что сделано, что нужно от заказчика, что не сделано и почему.
6. Ничего не деплоить и не публиковать без явной просьбы заказчика.

- `.gitignore` (node_modules, dist, .wrangler, .env, .dev.vars, .astro), `.env.example` с перечнем будущих переменных (см. задачи 8, 9, 11), `.editorconfig`, `.prettierrc` с плагином для Astro.
